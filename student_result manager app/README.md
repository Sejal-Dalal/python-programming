# Student Result Manager App 🎓

A simple console-based Python application for managing student names, marks, and results.

## 📌 Project Overview

The Student Result Manager App allows users to add students with their marks, view stored student records, and check whether a student has passed or failed.

The project is designed as a beginner-friendly Python project to practice fundamental programming concepts such as dictionaries, loops, conditional statements, and user input.

## ✨ Features

* Add student name and marks
* View all stored students
* Check student result
* Displays PASS if marks are 40 or above
* Displays FAIL if marks are below 40
* Exit the application
* Handles invalid menu choices

## 🛠️ Technologies Used

* Python 3
* Python Dictionary
* Conditional Statements
* While Loop
* User Input

## 📚 Concepts Practiced

* `while` loop
* `if-elif-else`
* Dictionary
* Dictionary `.items()`
* `in` operator
* `input()`
* Type conversion using `int()`
