# 🎯 Guessing Number Game

A simple Python-based number guessing game for beginners.

## 📌 Description

In this game, the computer randomly selects a number between 1 and 10.
The player has to guess the correct number.

After every wrong guess, the program gives a hint:
- 🔼 "Too high" if the guess is greater than the number.
- 🔽 "Too low" if the guess is smaller than the number.

The game continues until the player guesses the correct number.

## 🛠️ Technologies Used

- Python
- Random module

## ✨ Features

- Generates a random number between 1 and 10.
- Takes user input for guessing.
- Gives "Too high" or "Too low" hints.
- Continues until the correct number is guessed.
- Beginner-friendly Python project.

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Open the project in PyCharm or any Python IDE.
3. Run the Python file.
4. Enter your guess when prompted.
